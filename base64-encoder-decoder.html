Base64 Encoder / Decoder

Enter some text and click Encode or Decode.

Everything is processed in your browser. Nothing is uploaded or stored. Base64 is an encoding, not encryption, so do not use it to protect secrets.

How the Base64 encoder and decoder works

The Base64 encoder and decoder converts text to Base64 and back again. Type or paste text into the input box, then click Encode to turn it into Base64, or paste Base64 into the box and click Decode to turn it back into readable text. The tool supports full UTF-8, so text in any language works correctly. There is also a URL-safe option, which uses a variant of Base64 that is safe to put in web addresses. The Swap button exchanges the input and output, and Copy Output copies the result to your clipboard.

How to use it

  1. Type or paste your text or Base64 code into the input box.
  2. Tick the URL-safe Base64 box if you need the result for a web address.
  3. Click Encode to convert text to Base64, or Decode to convert Base64 back to text.
  4. Copy the output, use Swap to reverse the direction, or Clear to start over.

What you can use it for

Embedding data in links and settings. Some systems only accept plain text. Encoding data as Base64 lets you pass images, tokens, or configuration values through places that would otherwise break on special characters.

Reading encoded values. When you receive a Base64 string in an email, a config file, or an API response, decoding it here shows you the original text in seconds.

Working with web addresses. The URL-safe option produces Base64 that can go directly into a query string without the plus, slash, and equals characters that cause problems in URLs.

Frequently asked questions

What is Base64?

Base64 is a way of representing data with 64 safe characters: letters, digits, and two symbols. It is used when data has to travel through systems that only handle plain text, such as email and web addresses.

Is Base64 encryption?

No. Base64 is encoding, not encryption. Anyone can decode a Base64 string, so it does not hide information. Never use it to protect passwords or other secrets.

What does the URL-safe option do?

Standard Base64 uses the characters + and /, which have special meanings in web addresses, and pads the end with =. The URL-safe variant replaces + with -, / with _, and drops the padding, so the result can be placed in a URL without breaking it.

Does it support text in other languages?

Yes. The tool has full UTF-8 support, so Chinese, Arabic, emoji, and other non-English text encode and decode correctly.

What happens if I decode invalid Base64?

The tool shows an error instead of a result. Check that you copied the whole string, including any = padding at the end, and that you did not add extra spaces or line breaks.
