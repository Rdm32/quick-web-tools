How the PDF merger works

This free tool combines several PDF files into a single PDF, in the order you choose. Every page of every file is kept, in the order the files appear in the list, and the result downloads as one file named merged.pdf. Everything runs in your browser, so your files are never uploaded to a server.

How to use it

  1. Click the drop area (or drag files onto it) and choose two or more PDF files.
  2. Check the list: each file shows its name, page count, and size. Use the up and down arrows to reorder the files, or the remove button to take one out.
  3. Press Merge PDFs. The combined file downloads automatically as merged.pdf.

What you can use it for

Reports and applications. Combine a cover letter, a resume, and certificates into one PDF to send as a single attachment instead of several separate files.

Scanned documents. If a scanner saved each page or chapter as its own PDF, merge them back into one complete document in the right order.

Chapters and handouts. Join separate PDF chapters, slides, or handouts into one file that is easier to store, share, or print.

Frequently asked questions

How many PDF files can I merge?

You need at least two PDF files to merge. There is no fixed limit in the tool, but very large files take longer to process, because everything runs in your browser on your own device.

Are my files uploaded anywhere?

No. The merge runs entirely in your browser on your own device. Your PDF files are never sent to a server, stored, or shared with anyone.

Can I change the order of the files?

Yes. Each file in the list has up and down buttons, so the pages appear in the merged PDF in exactly the order you set. You can also remove any file you no longer need.

What happens if one of my PDFs is damaged or password-protected?

That file is skipped and named in a message, and the merge continues with the files that could be read. If no file can be read, no PDF is created and you will see an error message instead.

Does merging change the content of my PDFs?

No. The pages are copied into the new file unchanged, in the same order, so the text, images, and layout of each page stay as they were in the original files.
