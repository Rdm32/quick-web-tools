How the password generator works

The password generator creates a strong, random password in one click. You choose the length with a slider, from 6 to 64 characters, and tick which character types to include: uppercase letters, lowercase letters, numbers, and symbols. There is also an option to leave out ambiguous characters that are easy to confuse, such as the digit 0 and the letter O. Every password is generated on your device with the browser's secure random number generator, so it is never sent over the internet or stored anywhere.

How to use it

  1. Drag the length slider to set how long the password should be. The default is 16 characters.
  2. Tick or untick the character types you want: uppercase, lowercase, numbers, and symbols.
  3. Tick "Exclude ambiguous characters" if you plan to read or type the password by hand.
  4. Click Generate New Password, then use the Copy button to copy it.

What you can use it for

New accounts. Whenever you sign up for a website or app, generate a fresh password instead of reusing one you already have. A unique password for every account means one leaked password cannot unlock your other accounts.

Replacing weak passwords. If you still use a short password, a pet's name, or a birthday, generate a long random replacement and update the account. Longer passwords with mixed character types are far harder to guess.

Wi-Fi and shared logins. A random password works well for a home Wi-Fi network or a shared family account, where you need something strong that nobody has to memorize on the spot.

Frequently asked questions

How long should my password be?

Longer is stronger. A 16-character password with mixed character types is a good default for most accounts. For important accounts such as email and banking, 20 characters or more is even better. The strength meter shows an entropy estimate in bits, and a higher number means the password is harder to guess.

What are ambiguous characters?

They are characters that look alike in many fonts: the digit 0 and the letter O, the digit 1 and the lowercase letter l, and the uppercase letter I. Leaving them out makes a password easier to read aloud or type from a printed note.

Is my password sent to a server?

No. The password is created in your browser with the built-in secure random number generator. It never leaves your device, and this website does not see or store it.

Should I use the same password for every account?

No. If one website leaks its passwords, attackers try the same password on your email, bank, and social accounts. Use a different generated password for each account and keep them in a password manager.

What does the strength meter mean?

The meter estimates the password's entropy in bits, which measures how many guesses an attacker would need on average. A longer password and a wider mix of character types both raise the number. Aim for the highest strength label the meter shows.
