How the image resizer works

This free image resizer changes an image to the exact pixel size you type, using the canvas element in your browser. Your image is never uploaded to a server, and your original file is never changed: the tool saves a new resized copy when you press Download.

How to use it

  1. Drag an image into the box above, or click it to choose a file from your device.
  2. Type the width and height you want, or pick a scale percentage or a preset size. With "Keep aspect ratio" checked, changing one side updates the other automatically.
  3. Choose PNG or JPG. For JPG, move the quality slider to balance file size and sharpness.
  4. Press "Download resized image" to save the resized copy.

What you can use it for

Social media. Resize photos to the sizes profiles and posts need, such as 512x512 for a profile picture or 1920x1080 for a banner or cover image.

Websites and blogs. Shrink large camera photos to 800x600 so your pages load faster and use less bandwidth, without changing how the photo looks at normal size.

Documents and forms. Some uploads ask for exact dimensions, such as 300x300. Type the required size and download a copy that fits the requirement.

Frequently asked questions

Does the resizer upload my image?

No. The image is resized in your browser with the canvas element. It is never sent to a server, stored, or shared with anyone.

Will enlarging an image make it blurry?

Yes. Enlarging beyond the original size will soften the image, because the canvas has to stretch the existing pixels and cannot add detail that was never there. For the sharpest result, resize down rather than up.

What sizes can I enter?

Width and height must each be a whole number between 1 and 10000 pixels. If you enter a value outside that range, the tool shows an error instead of downloading.

Should I choose PNG or JPG?

Choose PNG for graphics, screenshots, and images with text or transparency, because PNG is lossless. Choose JPG for photos, because JPG files are usually much smaller. JPG does not support transparency, so transparent areas become white in a JPG download, and the quality slider only applies to JPG.

Does resizing change the file size?

Usually, yes. Resizing to fewer pixels makes the file smaller, and a lower JPG quality setting makes it smaller still. The exact size depends on the image, the format, and the quality you choose, so check the downloaded file if size matters.
