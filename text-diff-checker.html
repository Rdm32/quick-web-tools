How the text diff checker works

This free text diff checker compares two texts line by line and highlights exactly what changed. Paste the original text on the left and the changed text on the right, then press Compare. Added lines appear in green, removed lines appear in red, and unchanged lines appear in neutral grey, with a summary counting how many lines were added, removed, and left unchanged. Everything runs in your browser, so your text is never uploaded to a server or saved anywhere.

How to use it

  1. Paste the original text into the "Original text" box and the new version into the "Changed text" box.
  2. Press Compare to see added lines in green, removed lines in red, and unchanged lines in grey.
  3. Read the summary above the result to see how many lines were added, removed, and unchanged.
  4. Use Swap to exchange the two texts, or Clear to empty both boxes and start again.

What you can use it for

Checking document revisions. Compare two versions of an essay, article, or report to see which lines were added or deleted between drafts.

Reviewing code or config changes. Paste two versions of a file to spot which lines changed before you save or share the new version.

Spotting edits in copied text. If someone returns an edited copy of your text, a line-by-line diff shows at a glance what they changed.

Frequently asked questions

Does it compare word by word or line by line?

Line by line. The comparison splits each text into lines and matches whole lines. If you change a single word inside a line, that whole line is shown as removed from the original and added in the new version, because the line as a whole is no longer identical.

Is my text uploaded or saved anywhere?

No. The comparison runs entirely in your browser on your own device. Nothing is uploaded to a server, stored, or shared with anyone.

What happens if one box is empty?

The tool shows a message asking you to fill in both boxes. It needs text on both sides to compare, so an empty box cannot produce a diff.

What does the Swap button do?

Swap exchanges the contents of the two boxes, so the original becomes the changed text and vice versa. This is useful if you pasted the two versions in the wrong order and want to reverse the direction of the comparison.

How does the comparison work?

It uses a longest common subsequence algorithm, which finds the longest set of lines that appear in the same order in both texts. Lines in that shared set are unchanged; the remaining lines in the original are removed, and the remaining lines in the changed text are added.
